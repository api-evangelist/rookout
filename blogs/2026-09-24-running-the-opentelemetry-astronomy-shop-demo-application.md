Many companies are interested in experimenting with the OpenTelemetry observability standard, but have suffered from the lack of a good reference implementation. Now with Astronomy Shop, the OpenTelemetry demo app, organizations can kick the tires using multiple sample microservices that showcase OpenTelemetry features and capabilities. Learn how to deploy and explore OpenTelemetry features using Dynatrace as your full-context OpenTelemetry backend.
